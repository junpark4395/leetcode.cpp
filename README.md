# leetcode.cpp

LeetCode & NeetCode solutions in modern C++23.

```sh
make        # build main.cpp
make run    # build and run
make clean  # remove build artifacts
```

Run an archived solution:

```sh
make SRC='archive/leetcode/two-sum.cpp' run
```

- `main.cpp` — active problem
- `archive/leetcode/`, `archive/neetcode/` — archived solutions
